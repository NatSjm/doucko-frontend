# Icons

Original 24×24 rounded stroke icons: 2.25 stroke, round caps and joins. The files are drawn in ink `#1b1f3b` (the light theme's `ink`). On dark grounds or coloured stickers, use the `Icon` component instead, which draws with `currentColor`.

- States:
  - `check`: correct / Správně
  - `retry`: Skoro!, replay a mission
  - `eye`: revealed answer
- Tools:
  - `hint`: Nápověda
  - `translate`: translation toggle
  - `flag`: Nahlásit problém
- Go:
  - `arrow`: Pokračovat / Odeslat
  - `bolt`: start a mission, XP
- Rewards: `star` (rank stars), `sparkle` (celebrations, medal)
- Other: `lock` (a subject or mission coming later)
- Subjects: `math`, `book` (Český jazyk), `chat` (Anglický jazyk), `leaf` (Přírodopis), `globe` (Zeměpis), `temple` (Dějepis). A new subject gets a new icon in the same style.
